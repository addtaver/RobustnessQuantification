# Robustness Quantification

This repository contains the code and data used for the 2026 PGM paper "Local Robustness Quantification for Naive Bayes Classifiers and Generative Forests: a General Approach".
The code is written in Python and the experiments are run in Jupyter notebooks. The results of the experiments are stored in the results_PGM folder, which contains all the files needed to create the figures and tables in the paper.
